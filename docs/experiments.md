### Smoke test (code validation, not a real experiment)

The pipeline was validated end-to-end against a small **synthetic**
NIfTI dataset generated in the build environment (6 fake volumes, 64×64×20
voxels, with an injected synthetic tumor blob) — not real medical imaging
data, and not the MSD dataset. This confirmed the code runs correctly, not
that the model performs well. Verified: dataset discovery, patient-level
splitting (zero cross-split patient overlap), sample loading, model
instantiation, forward pass, loss computation, one training step, a full
2-epoch training run, evaluation, and visualization output — all executed
successfully as real CLI subprocess calls, and dataset-integrity error
handling (bad path, missing label file, invalid split fractions, missing
checkpoint) raised the correct errors. No Dice/IoU numbers from this smoke
test are reported as project results — they reflect an undertrained model
on fake data and would be meaningless as a metric.

## Classification — ViT-Base on 4-class brain tumor MRI

### Prior work (not reproduced in this repository)

From the separate `brain-tumor-cross-dataset-classification` project:
- MobileNetV2 (best of ResNet50 / EfficientNetB0 / MobileNetV2 compared via
  transfer learning): **91.75% accuracy, 91.69% F1-score** on the 4-class
  brain tumor MRI dataset (7,023 images)
- Cross-dataset generalization to an independent external Figshare dataset
  (3,064 images): 86.13% accuracy, 5.62% generalization gap
- Grad-CAM used for interpretability

These numbers are reported as prior work for comparison context only. They
were not generated by this repository's code.
